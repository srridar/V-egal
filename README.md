# Vegal - Multi Feature Chat Application 🚀

A full-stack real-time chat application built with **Next.js, Socket.io, Node.js, and MongoDB**.

---

## 🔥 Features

- 💬 Real-time chat (1-to-1 & group)
- 📞 Audio & Video calls (WebRTC)
- 📁 File sharing (Images, PDFs, Docs)
- 🎤 Voice messages
- 👥 Friend system
- 🔔 Real-time notifications
- 🔐 Authentication system (JWT + cookies)
- 🟢 Online/offline user status

---

## 🛠 Tech Stack

- Next.js (App Router)
- TypeScript
- Socket.io
- Node.js + Express
- MongoDB + Mongoose
- WebRTC (calls)
- Cloudinary (file uploads)
- Redux Toolkit
